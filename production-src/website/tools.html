01 / macOS app● Version 2.6.1

Talking Tom

A native macOS app that turns PDF, Word, and plain text into spoken audio. Standard cleanup runs on your Mac; AI cleanup, translation, and chart narration are optional. Independent tabs, a compact player, and pitch-preserving speed controls make it practical for long readings.

Why I built it. Computer science and philosophy both involve a lot of reading. I wanted a way to move dense papers off my desk and into a walk—and to replace another subscription with a tool shaped around the way I actually study.

  • macOS 26+
  • Apple Silicon (M1+)
  • Native app + source
  • Optional AI with your Anthropic key
  • English + Spanish

macOS security. The included app is locally signed for integrity, but is not Developer ID signed or notarized by Apple. The source installer is unsigned. See Apple’s security guidance if macOS cannot verify the developer. If it reports malware or says the app will damage your Mac, stop and report the exact warning. No API keys or personal settings are included.

Need to force-open the installer? Use Apple’s per-app security override in step 3 below. It approves only this installer; do not disable Gatekeeper or remove quarantine protection.

New in 2.6.1: updated voice-service compatibility. Setup includes the speech client compatible with Microsoft’s October 2026 authentication change. Connection, certificate, timeout, and service rejection failures now have distinct messages. The native release also includes independent tabs, two-column PDF reading order, automatic model selection, and opt-in visual narration.

Updating? Quit Talking Tom, then run setup.command from the new download. Settings, drafts, recordings, and transcripts are preserved. The previous app and runtime are backed up and restored if setup fails.

Open-source personal project. Talking Tom is not affiliated with or endorsed by Outfit7, Microsoft, or Anthropic. Speech generation sends narration text to Microsoft’s online voice service. Standard cleanup and narration need no API key. Optional AI features send text and selected PDF images to Anthropic and incur API charges. Settings, recordings, and transcripts stay on your Mac.

01 / CLEAN

Reads what matters

Standard cleanup removes citations and common PDF clutter on your Mac. Choose Claude for more complex cleanup. PDF import follows the reading order of common two-column research papers.

02 / VOICE

English, Spanish, or both

Choose English or Spanish voices and narrate the original language without an API key. “Read in” offers optional Claude translation; chart and table narration is also opt-in.

03 / LISTEN

A real audio player

Scrub the waveform, skip 15 seconds, and listen from 0.5× to 2× without shifting pitch. Use independent tabs or the compact player. The MP3 and transcript are saved together.

Install and use+
  1. Check the requirements. You need an Apple Silicon Mac (M1 or newer), macOS 26 or newer, and internet access. This download does not support Intel Macs. No existing Python, Homebrew, or Xcode installation is needed. An Anthropic key is only needed for optional AI features.
  2. Review the installer. Download and unzip the file, open the talking-tom-2.6.1 folder, and read README.md before opening setup.command. The download includes the native app and its source. It is not Developer ID signed or notarized by Apple.
  3. If macOS blocks setup.command, force-open it with Apple’s per-app override.
    1. Try to open setup.command once so macOS records the blocked attempt.
    2. Open System Settings → Privacy & Security, scroll to the Security section, and click Open Anyway beside the message about setup.command.
    3. Authenticate if macOS asks, then click Open in the warning that appears. Terminal should begin the setup.
    4. Use this override only for the “cannot verify the developer” warning. If macOS says the file contains malware or will damage your Mac, stop and do not bypass that warning.
  4. Let setup finish. A Terminal window downloads a private Python runtime and dependencies, then installs Talking Tom in ~/Applications/. Wait for the installation confirmation before opening the included app. You can then delete the downloaded folder.
  5. Open the app. Launch Talking Tom from Applications. Choose English or Español in Settings. For free narration, select Standard cleanup and Original language.
  6. Connect Claude if you want AI features.
    1. Use Anthropic’s official API overview ↗ for its current setup guidance.
    2. Create or manage your key on Anthropic’s API Keys page ↗. Anthropic’s Billing page ↗ contains its current payment and credit options.
    3. Open Settings in Talking Tom, paste your Anthropic API key, and save it.
  7. Choose a document and listen. Select a PDF, Word (.docx), or text file—or paste text—then choose a voice, speed, cleaning mode, and output language. Talking Tom saves the MP3 and transcript in ~/Talking Tom/.

02 / macOS utility● Version 1.0.1

Claude Code Rate-Limit Resumer

An open-source macOS utility that detects when Claude Code reaches a session rate limit, waits until one minute after the stated reset time, and automatically sends continue work back into the same session. It runs locally, makes no network requests, and does not access project source code.

  • macOS
  • Python 3.9+
  • Claude Code
  • tmux
Download ZIP ↓ Installation instructions ↓ ZIP · 11.2 KB

Community project. This is an unofficial tool and is not affiliated with or endorsed by Anthropic. Claude Code hooks run with your user permissions, so review the included resumer.py and install.py before installing.

01 / DETECT

Reads the rate limit

Uses Claude Code’s StopFailure hook and only reads the rate-limit error fields or visible text in its own tmux pane.

02 / WAIT

Resumes at the right time

Waits until one minute after the displayed reset time, then targets the same tmux pane instead of whichever Terminal window is in focus.

03 / VERIFY

Fails safely

It records Claude Code’s foreground process when the limit occurs and will not type if the pane is gone or that process has changed.

Install and use+
  1. Check the requirements. You need macOS, Python 3.9 or newer, a current Claude Code installation with StopFailure hook support, and tmux. If tmux is missing, install it with Homebrew:
    brew install tmux
  2. Install the utility. Download and extract the ZIP, open Terminal in the extracted folder, and run:
    python3 install.py

    The installer copies the utility into ~/.local/share, backs up your existing Claude settings, and adds the rate-limit hook without replacing your other settings.

  3. Run Claude Code inside tmux. From your project directory, start or reconnect to a named tmux session, then continue your conversation:
    tmux new-session -A -s claude-work
    claude --continue

    Use claude --resume instead when you need to choose a different saved conversation.

  4. Verify the hook. In Claude Code, run /hooks and confirm that StopFailure → rate_limit appears.
  5. Leave it running. When a rate limit occurs, the utility waits and sends only continue work to the original session. Your Mac must remain awake. Detach from tmux with Ctrl+B, then D; reconnect with the same tmux command.

Check status

~/.local/share/claude-rate-limit-resumer/resumer.py status

Watch logs

tail -f ~/.local/state/claude-rate-limit-resumer/resumer.log

Uninstall

python3 install.py uninstall

Run this from the extracted release folder. It removes the hook and installed script while preserving local logs for inspection.

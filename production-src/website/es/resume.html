Proyectos de IA e investigación

Adaptive Development Orchestrator

JavaScript · Claude Code · JSON Schema

  • Creé un sistema que analiza el código existente, divide las solicitudes en tareas manejables y coordina agentes para ejecutarlas en el orden adecuado.
  • Asigné tareas según su dificultad y las capacidades de cada modelo para controlar costes y reservar los modelos más potentes para razonamientos complejos.
  • Configuré agentes independientes de revisión y verificación para documentar criterios de aceptación, comandos de prueba, códigos de salida y resultados satisfactorios, fallidos o sin verificar, exigiendo aprobación explícita del usuario para los lanzamientos.

Modelo de lenguaje de tipo GPT

Python · PyTorch

  • Implementé y entrené un transformer de tipo GPT con textos de acceso público, incluyendo representaciones de tokens, atención causal multicabeza, conexiones residuales y normalización de capas.
  • Construí un bucle de entrenamiento para predecir el siguiente token y examiné los textos generados.

Sistema de texto a voz

Python · Tkinter · Claude API · Edge TTS

  • Creé y publiqué una aplicación para macOS que convierte documentos PDF, Word y texto en audio, combinando reglas y asistencia de Claude para limpiar citas, encabezados y errores de OCR.
  • Añadí traducción y narración en inglés y español, controles de velocidad que conservan el tono y transcripciones guardadas.

Alineación de la IA y autonomía humana

Investigación filosófica en curso

  • Investigo cómo debe contemplar la alineación de la IA la autonomía humana, con el objetivo de orientar el diseño de sistemas que mejoren la eficiencia sin reducir la capacidad de las personas para tomar decisiones y dirigir su trabajo.

01 / utilidad para macOS● Versión 1.0.1

Claude Code Rate-Limit Resumer

Una utilidad de código abierto para macOS que detecta cuando Claude Code alcanza el límite de una sesión, espera hasta un minuto después de la hora de restablecimiento indicada y envía automáticamente el texto literal continue work a esa misma sesión. Se ejecuta de forma local, no realiza solicitudes de red ni accede al código fuente de tus proyectos.

  • macOS
  • Python 3.9+
  • Claude Code
  • tmux

Proyecto comunitario. Esta es una herramienta no oficial, sin afiliación ni respaldo de Anthropic. Los hooks de Claude Code se ejecutan con los permisos de tu usuario; revisa los archivos resumer.py e install.py incluidos antes de instalarla.

01 / DETECTAR

Lee el límite de la sesión

Utiliza el hook StopFailure de Claude Code y solo lee los campos del error del límite o, como alternativa, el texto visible en su propio panel de tmux.

02 / ESPERAR

Reanuda en el momento adecuado

Espera hasta un minuto después de la hora mostrada y apunta al mismo panel de tmux, no a la ventana de Terminal que esté activa.

03 / VERIFICAR

Falla de forma segura

Registra el proceso de Claude Code que está en primer plano cuando se alcanza el límite y no escribe nada si el panel desaparece o el proceso cambia.

Instalación y uso+
  1. Comprueba los requisitos. Necesitas macOS, Python 3.9 o una versión posterior, una instalación actual de Claude Code compatible con el hook StopFailure y tmux. Si no tienes tmux, instálalo con Homebrew:
    brew install tmux
  2. Instala la utilidad. Descarga y descomprime el ZIP, abre Terminal en la carpeta extraída y ejecuta:
    python3 install.py

    El instalador copia la utilidad en ~/.local/share, crea una copia de seguridad de la configuración existente de Claude y añade el hook del límite sin reemplazar tus demás ajustes.

  3. Ejecuta Claude Code dentro de tmux. Desde la carpeta de tu proyecto, inicia o vuelve a conectarte a una sesión de tmux con nombre y continúa la conversación:
    tmux new-session -A -s claude-work
    claude --continue

    Utiliza claude --resume si necesitas elegir otra conversación guardada.

  4. Verifica el hook. En Claude Code, ejecuta /hooks y confirma que aparezca StopFailure → rate_limit.
  5. Déjalo funcionando. Cuando se alcanza el límite, la utilidad espera y envía únicamente continue work a la sesión original. El Mac debe permanecer activo. Para salir de tmux sin detenerlo, pulsa Ctrl+B y después D; vuelve a conectarte con el mismo comando de tmux.

Consultar el estado

~/.local/share/claude-rate-limit-resumer/resumer.py status

Seguir los registros

tail -f ~/.local/state/claude-rate-limit-resumer/resumer.log

Desinstalar

python3 install.py uninstall

Ejecuta este comando desde la carpeta extraída. Elimina el hook y el script instalado, pero conserva los registros locales para poder revisarlos.

02 / aplicación para macOS● Versión 1.0.0

Talking Tom

Una aplicación de código abierto para macOS que convierte un PDF, un documento de Word o un archivo de texto en audio listo para escuchar. Quita citas, encabezados repetidos, números de página y ruido de OCR; después narra el texto útil con una voz neuronal de Microsoft Edge. El reproductor con onda de sonido, el control de velocidad que conserva el tono y la transcripción guardada junto al audio hacen que funcione bien incluso con lecturas largas.

Por qué la construí. Informática y filosofía vienen con mucha lectura. Quería sacar los textos densos del escritorio y llevármelos a caminar, además de sustituir otra suscripción por una herramienta adaptada a mi forma real de estudiar.

  • macOS
  • Intel + Apple Silicon
  • Instalación autónoma
  • Clave de Anthropic obligatoria
  • Inglés + español
Descargar ZIP ↓ Instrucciones de instalación ↓ ZIP · 1,2 MB

Proyecto personal de código abierto. Talking Tom no es un producto oficial ni está afiliado o respaldado por Outfit7, Microsoft o Anthropic. La aplicación necesita una clave de la API de Anthropic para procesar los documentos con Claude. El texto que se va a narrar se envía al servicio en línea de voces de Microsoft Edge para generar el audio, y el contenido del documento se envía a Anthropic mediante tu clave de API. Los ajustes, el audio generado y las transcripciones se guardan localmente en tu Mac.

01 / LIMPIAR

Lee lo que importa

Un sistema de reglas integrado elimina citas, encabezados, pies, números de página y palabras partidas por el OCR. Después, Claude se ocupa de documentos más desordenados sin perder su sentido ni su estructura.

02 / VOZ

Inglés, español o ambos

Elige entre voces neuronales en inglés y español. Claude prepara el documento antes de narrarlo y «Leer en» puede traducirlo independientemente del idioma elegido para la interfaz.

03 / ESCUCHAR

Un reproductor de verdad

Recorre la onda de sonido, salta diez segundos y escucha entre 0,5× y 2× sin alterar el tono. El MP3 y su transcripción de texto se guardan juntos.

Instalación y uso+
  1. Comprueba los requisitos. Necesitas un Mac—Intel o Apple Silicon—, conexión a internet y una clave de la API de Anthropic. No hace falta instalar Python, Homebrew ni ningún otro programa.
  2. Configúralo una sola vez. Descarga y descomprime el archivo. Abre la carpeta talking-tom-1.0.0, haz clic derecho en setup.command y elige Abrir. No hagas doble clic: macOS bloquea los scripts descargados hasta que usas clic derecho → Abrir una vez. Cuando aparezca el aviso de seguridad, vuelve a pulsar Abrir.
  3. Espera a que termine la instalación. Se abrirá una ventana de Terminal que descargará una copia privada de Python y las dependencias, creará Talking Tom en tu carpeta Aplicaciones y pondrá un acceso directo en el Escritorio. Tarda unos dos minutos. Cuando Terminal muestre Done., ya puedes borrar la carpeta descargada.
  4. Abre la aplicación. Inicia Talking Tom desde Aplicaciones o el acceso directo del Escritorio. La primera vez, elige English o Español; podrás cambiarlo más adelante en Ajustes.
  5. Conecta Claude antes de usar Talking Tom.
    1. Consulta la guía oficial de la API de Anthropic ↗ para seguir sus instrucciones actuales.
    2. Crea o administra tu clave en la página oficial de claves de API ↗. La página de facturación de Anthropic ↗ contiene sus opciones actuales de pago y crédito.
    3. Abre Ajustes en Talking Tom, pega tu clave de la API de Anthropic y guárdala.
  6. Elige un documento y escucha. Selecciona un PDF, un documento de Word (.docx) o un archivo de texto—o pega el texto—y elige la voz, la velocidad, el modo de limpieza y el idioma final. Talking Tom guarda el MP3 y la transcripción en ~/Talking Tom/.

Iniciar
